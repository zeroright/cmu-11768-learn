作业与项目

CMU 11-768 三次编程作业（HW1/HW2/HW3）+ 期末项目，对应 harness / 评测 / 训练三条主线。

三次编程作业

作业主题对应讲次说明
HW1Agent Harness：搭一个最小 agent loopL01-L05写 tool dispatch、observation、context 管理
HW2Agent 评测：构造任务集与衡量指标L06-L10对 Coding / GUI / Research 任选一个领域做评测
HW3Agent 训练：SFT 或 RL 微调一个 agentL08-L12用 HW2 的评测反馈训练模型

期末项目

用学到的能力整合到一个自己选的任务上：可以是新 benchmark、改进现有方法、或者部署一个真正可用的 agent 系统。详细要求见官方 课程站 与 Canvas。
