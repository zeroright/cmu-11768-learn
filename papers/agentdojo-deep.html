AgentDojo 深度精读：间接 prompt injection 的可复现红队

Debenedetti et al., NeurIPS 2024 · arXiv 2406.13352

威胁模型：间接 prompt injection

直接越狱是让 model 做坏事；间接 injection 是把恶意指令藏在 agent 要读的环境文档（邮件/网页/文件）里，agent 读到后被劫持执行非预期动作。这是 agent 特有的攻击面，传统 safety 不覆盖。

环境设计：可控可复现

AgentDojo 提供一组带工具（邮件、日历、文件、银行）的模拟环境，每个 task 有预期动作；attacker 在 env 内容里植入 instruction，看 agent 是否执行注入的恶意 action 而不是用户的 task。

两种量化指标

1) Utility：agent 完成用户 task 的比例；2) Security：attacker 目标 action 被执行的比例（越低越好）。好 defense 要同时高 utility、低 security compromise。

关键发现

当时的最强 agent（GPT-4/Claude）在多种 attack 下都有 30%+ 的 compromise rate；而加 defense（如 prompt hardening、tool filter）只能部分缓解，且往往伤 utility。这说明间接注入不是已解决的问题，而是开放研究。

对生产 agent 的启示

1) env 里的不可信内容（邮件、网页、文件）必须标记为 untrusted；2) 高权限动作（发邮件、转账、删数据）必须 human-in-loop；3) 监控要看 trajectory，不是只看 final answer；4) 定期用 AgentDojo 类环境回归红队。

附 · 间接注入流程与防御层

攻击者把恶意指令埋进 env 内容，agent 读到后被劫持执行非预期动作；防御不是单层，而是 4 层组合。

怎么读它

把它当作「如何系统地评估 agent 安全」的方法论模板：威胁模型 → 受控环境 → 双指标（utility/security）→ attack/defense 对比。如果你想给自家 agent 做安全评测，可以照这个模板复制。
